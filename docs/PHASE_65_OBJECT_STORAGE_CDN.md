# PlayHub Phase 65: Object Storage (S3/R2) & Edge CDN Media Pipeline

## 1. Executive Summary
Phase 65 implements a provider-agnostic, production-grade **Object Storage & Edge CDN Media Pipeline** for PlayHub. The architecture supports Amazon S3, Cloudflare R2, and local storage targets. To protect platform performance and security, binary media uploads bypass NestJS application servers and push directly from client applications to S3/R2 via short-lived presigned URLs generated by `MediaService`.

## 2. Storage Architecture & Privacy Boundaries
```
[ Client Application ] ──► [ POST /api/v1/media/presign ] ──► [ NestJS MediaService ]
                                                                      │ (Validate MIME, Size,
                                                                      │  Tenant Ownership & Key)
                                                                      ▼
[ Direct PUT Upload ] ◄── [ Presigned Upload URL ] ◄─────────────────┘
         │
         ▼
[ S3 / R2 Object Storage ]
         │
         ▼
[ POST /api/v1/media/:id/complete ] ──► [ Head Object Verification ]
                                                  │
                                                  ├─► [ Public Venue Media ] ──► CDN Base URL
                                                  └─► [ Private KYC Document ] ──► Short-lived Signed Download URL
```

### Media Categories & Privacy Policies:
- **`VENUE_MEDIA` & `FACILITY_MEDIA` (Public)**:
  - Allowed MIMEs: `image/jpeg`, `image/png`, `image/webp` (Max 10MB).
  - Storage Key: `organizations/${orgId}/venues/${venueId}/media/${uuid}.${ext}`
  - Delivery: Delivered publicly via CDN (`STORAGE_PUBLIC_BASE_URL`).
- **`KYC_DOCUMENT` (Private)**:
  - Allowed MIMEs: `application/pdf`, `image/jpeg`, `image/png` (Max 15MB).
  - Storage Key: `organizations/${orgId}/kyc/${documentType}/${uuid}.${ext}`
  - Delivery: Restricted. Download access requires authentication & `OrganizationGuard` / `PlatformAdminGuard`. Delivered via short-lived signed download URLs (TTL = 300s).

  - Added spatial indexes: `@@index([category])`, `@@index([status])`, `@@index([entityType, entityId])`.

## 4. Asynchronous Image Processing (BullMQ Worker)
- Queue: `media`
- Worker: `MediaWorker` (`backend/src/queues/workers/media.worker.ts`) handles background thumbnail generation and media state transitions.

## 5. API Endpoints
- `POST /api/v1/organizations/:orgId/media/presign`: Request presigned S3/R2 upload URL (`PresignUploadDto`).
- `POST /api/v1/organizations/:orgId/media/:id/complete`: Complete media upload following S3/R2 PUT.
- `GET /api/v1/organizations/:orgId/media/:id/download`: Request secure short-lived presigned download URL for private KYC documents.
- `DELETE /api/v1/organizations/:orgId/media/:id`: Delete media asset from PostgreSQL and object storage.
